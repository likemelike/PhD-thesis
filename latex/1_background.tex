\chapter{绪论}


\section{研究背景与意义}

\zhdigits*{\the\year} 年\zhnumber{\the\month} 月\zhnumber{\the\day} 日\;\xxivtime

随着移动互联网技术、社交网络以及GPS系统的普及,带有地理位置信息的时空-文本数据爆炸式增长。时空-文本数据既包括空间地理位置,也包括位置点的文本描述。位置信息可以定义为由经纬度组成的地理坐标或者特定的语义位置(如“北京大学”、“海淀区”、“北京市”、 “中国”)。 文本信息可以是文本文档、一组关键词集合、关键词和数值的组合等。此外，时空-文本对象还可以包含时间信息，如时间戳和时间段信息等。除了文本和地理空间信息之外，时空-文本内容还可以包括其它较为宽泛的信息，例如发布内容的用户、内容创建时间、内容类别信息和评级等。

时空-文本数据来源广泛。 其中，用户使用移动设备在社交网络中产生的社交数据(如旅游景点签到数据，网红餐厅打卡数据等)是时空-文本数据的重要来源,这些数据具有海量、高频、多维、异构等特点。
据悉，仅仅在2014年，Flickr上发布了超过4000万张照片，Wikipedia上有超过100万篇带有地理标签的文章\upcite{DBLP:journals/wpc/MemonCMLHC15}。 每天在Twitter上发布超过1000万条带有地理标签的推文，每天大约有800万次签到数据被提交到Foursquare。移动社交应用大致可以分为即时消息类、在线社交类、空间分享类、微博分享类等应用。即时消息类应用如QQ、微信等，用户通过即使消息传递社交信息，同时可以发送自己的位置信息。这些带有位置信息的文本消息，组成了社交网络中时空-文本数据的一部分。用户可以在线发布一些有价值的时空-文本消息，例如用户喜欢的餐厅、运动场、游乐场等。

海量且内容丰富的时空-文本数据催生了许多基于地理位置点的服务(LBS)。基于地理位置点的服务最初起源于20世纪70年代的紧急呼叫服务，随后在越来越多定位技术和计算平台支撑下，LBS发展出更多个性化的应用来服务社会。近年来，LBS开始利用移动终端等用户提供的位置信息,在特定计算平台支持下为用户提供对应的定制服务，如个性化的路线规划、兴趣点搜索和推荐等。如今，很多流行的LBS服务如网上购物、查找地方美食、旅游路线规划等，覆盖了日常生活的方方面面，为人们的生活带来了极大的便利。LBS位置点服务中的一种重要应用,基于地理位置点的关键字查询以及基于时空-文本大数据的特定的时空-文本对象搜索在基于位置的服务中具有重要的应用价值, 因而在近年来受到学术界和工业界的广泛关注。例如，可以利用关键字感知的最优路线规划为个人用户规划感兴趣的旅游路线，也可以使用范围关键字查询获取用户所在位置周围的意向餐厅或酒店等。对于移动终端用户，可以利用基于位置的服务进行路线导航、交通拥堵预防等，从而极大便利了人们的日常生活。对于企业，时空-文本对象搜索推荐服务可以帮助其进行店面选址、精确的管理调动等。对于社会，时空-文本对象的精确和快速搜索可以用于城市管理、紧急救援\upcite{zhiwang/hu08/lbsapp}等。
然而，针对日渐复杂且频繁的多样化查询，现有研究工作存在未考虑位置点文本属性、未引入隐私保护、不适用于数据流查询、无法保证查询结果的实时性返回等缺点。此外，随着智能手机的普及，新的应用场景不断出现, 人们获取时空-文本数据的需求越来越大，查询需求也日益多样化。现有的查询模型无法有效地表达用户的查询需求,导致查询结果与用户需求不匹配。或者查询效率不能满足用户的实时性需求，从而导致用户体验降低。综上，越来越多的应用场景使得用户查询需求日益多样化，这对查询模型的表达能力和响应速度提出了新的挑战。

作为关键字查询的重要分支,基于时空-文本大数据的查询综合利用空间邻近性和文本相关性对空间对象进行相应的查询，以满足用户的个性化需求。时空-文本数据的查询发生在两种情景下:一种是假设数据是相对静态的，查询请求是一次性的;另一种是考虑数据流的场景，需要对静态或动态的连续查询保持最新的查询结果。该领域查询任务可以分为三个主要的组成部分，一是构建查询模型，二是建立索引机制，三是设计对应的查询算法。其中，查询模型用于表达用户需求，如特定的关键字需求，空间范围限制等。其表达能力的强弱会影响查询结果与用户真实需求间的匹配程度，因此，如何设计更有效地查询模型来更好地建模用户需求是该领域面临的一个重要挑战。索引机制的构建目标是改进算法的运行效率，尽可能减少不必要的计算。时空-文本数据包含位置信息、关键字信息、时间信息以及其他额外的补充信息，具有海量和多维的特性。我们需要建立高性能的索引机制来组织这些空间数据以便于支持高效的查询，并且降低索引的空间存储开销。在建立索引时需要将空间信息和文本信息等有机结合起来，以便于设计更有效的剪枝过滤功能。此外，查询算法性能主要体现在查询效率、查询准确度、结果更新的实时性等方面。在很多应用场景下，查询任务对查询算法实时性要求较高，例如实时路线规划，在线舆情分析等。在这些情况下，我们需要研究可以实时返回查询结果的查询框架，从而满足查询任务所要求的实时响应能力。


综上，一个优质的查询算法不仅能保证计算结果的准确性，同时需要满足算法本身的高性能和可扩展性等。针对用户日益复杂的多样化的查询需求，设计面向时空-文本大数据的高性能算法是一个不可阻挡的趋势，具有十分重要的实际应用价值和理论研究价值。

随着汽车产业、智能移动设备以及基于位置服务的快速发展，带有地理位置信息的时空数据呈现爆炸式增长。其中，路网数据和轨迹数据是两个代表性的时空数据。路径规划、轨迹分析等基于时空数据挖掘的位置服务在城市计算中扮演着日益重要的角色。一个动态路网是由顶点集和边集构成的，其中顶点代表路段的连接点，交叉点；连边则代表具体的路段。每条边连接着两个顶点。为了便于描述，我们假定所有行程请求的起点和终点位置都已经被映射到离它们最近的顶点上。

路径规划不仅直接影响人们的日常出行方式，也关系到物流运输、智慧城市管理以及能源优化等多个领域。近年来，随着网络购物、共享出行和自动驾驶技术的发展，城市路网中行程请求呈现出高频、密集和动态的特点，传统基于单次行程或静态路径集合的最优路径规划方法已难以适应实时、连续的行程请求流。

综上，城市计算中面临的核心挑战包括大规模数据处理、动态环境适应以及对象间潜在交互的准确建模。围绕路径规划、联合移动模式挖掘、接触搜索与轨迹相似连接等任务，设计高效算法与索引结构不仅具有理论价值，也具有显著应用潜力：一方面可提升城市交通系统的调度效率与拥堵缓解能力；另一方面可支持公共卫生管理、生态监测及智能出行等多领域的决策优化。基于此，本文旨在系统研究城市计算中高效算法设计问题，通过统一的时空数据建模与高性能计算框架，实现对移动对象行为的实时、准确与可扩展分析，为智慧城市应用提供技术支撑。



\section{研究目标}
本文的总体研究目标可概括为在基于海量时空文本数据的场景中，在保证用户个性化位置查询结果准确性的前提下，满足用户实时查询这一需求下，设计有效的索引结构、高性能的搜索算法以解决基于给定路线的空间-文本相似位置点查询，面向时空-文本对象流上的空间关键字连续匹配以及面向大规模时空-文本对象流的相似度连接。该领域查询任务可以分为三个主要的组成部分，一是构建查询模型，二是建立索引机制，三是设计对应的查询算法。其中，查询模型用于表达用户需求，如特定的关键字需求，空间范围限制等。其表达能力的强弱会影响查询结果与用户真实需求间的匹配程度。索引机制的构建目标是改进算法的运行效率，尽可能减少不必要的计算。时空-文本数据包含位置信息、关键字信息、时间信息以及其他额外的补充信息，具有海量和多维的特性。我们需要建立高性能的索引机制来组织这些空间数据以便于支持高效的查询，并且降低索引的空间存储开销。在建立索引时需要将空间信息和文本信息等有机结合起来，以便于设计更有效的剪枝过滤功能。此外，查询算法性能主要体现在查询效率、查询准确度、结果更新的实时性等方面。推动上述三类主要的关键字或时空-文本对象查询和连接，本文定义具体目标分别如下。

\begin{enumerate}
    \item 针对“基于给定路线的空间-文本相似位置点查询方法”这一研究内容，本文应达到以下具体目标。
    \begin{itemize}
        \item 所定义的“时空-文本相似度函数”需要同时考虑位置点与给定路线之间空间域和文本域的相似度，能够在不同场景下准确表达用户的真实需求。同时，该相似度函数应该尽量简单。此外，该相似度函数应合理考虑空间域和文本域的重要性比重，符合现实场景。
        \item 所建立的“索引结构”易于维护，可以快速更新。该索引不仅具有较小的存储开销，索引时间较短。同时能够适应数据规模的变化，具有良好的可扩展性。所设计的查询算法需要与建立的索引结构相辅相成，从而满足实时性的现实需求。
        \item 所设计的“两阶段的搜索机制”能够保护用户在查询过程中的位置点偏好隐私。同时，该搜索机制的隐私保护特性应该是算法本身具有的，不能够带来额外的计算开销。否则，搜索算法效率会大大降低，可能不再满足实时性的需求。
    \end{itemize}
    
    \item 针对“面向时空-文本数据流的连续的空间关键字匹配方法”这一研究内容，本文应达到以下具体目标。
    \begin{itemize}
        \item 所定义的“面向大规模时空-文本位置流的CSK实时查询问题”能够符合用户的现实需求。其中每个CSK查询包括一组由“与”、“或”、“非”语义连接的关键字集合以及一个任意形状的查询区域。所构造的匹配规则应能够同时考虑空间覆盖率，文本覆盖率等指标，符合现实场景。
        \item 所设计的“连续的空间关键字查询索引机制”能够保证动态的索引更新，以及高效的索引查询。该索引结构易于维护，能够在预处理中提取有效的信息，提高索引效率。同时，建立的动态索引应该具有较小的存储开销和时间开销。此外，应具有良好的可扩展性以便适应数据规模的变化。
        \item 所设计的“高性能算法”能够利用所建立的索引，同时处理数以百万的CSK查询。此外，应允许在用户倒排索引项具有不同关键字、不同连接语义和不同空间区域形状上的CSK查询。同时，该查询所占用的内存开销也应较小。
        
    \end{itemize}
    
    \item 针对“面向大规模时空-文本对象流的相似度连接方法”这一研究内容，本文应达到以下具体目标。
    \begin{itemize}
        \item 所定义的“相似度函数”能够符合用户的现实需求，应该考虑到两个对象之间的空间邻近性、文本相关性和时间差距。
        \item 所设计的“混合的网格索引结构”能够有效地结合了时空-文本对象的空间信息、文本信息和时间信息。高效的索引方法，不仅能够减少索引存储开销，提升索引更新效率，并且具有良好的可扩展性，能够适应数据规模的变化。同时，该索引能够包含所有满足索引条件的对象，不存在遗漏或者错误的索引项。
        \item 所设计的“高性能连接算法”能够实时计算并返回时空-文本相似度连接的匹配结果。同时，能够处理高到达率的时空-文本数据流。不仅能适应数据规模的变化，而且能够满足不同的连接需求，具有较好的可扩展性。
        
    \end{itemize}
    
\end{enumerate}
\section{研究所面临的挑战}
为了实现上述目标，本文针对基于给定路线的空间-文本相似位置点查询、面向时空-文本数据流的连续的空间关键字匹配、面向大规模时空-文本对象流的相似度连接面临的以下几点主要挑战，设计有效的解决方案。
\begin{enumerate}
    \item  基于给定路线的空间-文本相似位置点查询
    \newline \indent
    高效处理“基于给定路线的空间-文本相似位置点查询”面临三个主要的挑战。其一，如何对空间相似度和文本相似度进行有效的建模, 如果仅仅但考虑空间域或文本域的相似度，查询结果可能无效；其二，如何在空间域和文本域中将搜索空间限制在一个相对较小的范围内，比如建立有效的修剪策略等；其三， 如何在返回查询结果时保护用户的个性化隐私。注意在保护隐私的同时，不能增加额外的计算消耗，否则可能降低算法的运行效率。
    
    \item 面向时空-文本数据流的连续的空间关键字匹配方法
    \newline \indent
    高效地处理CSK查询面临以下技术挑战。首先，CSK查询集的数量可能非常大。 其次，每个CSK查询都需要实时处理。 当数据流中的一个新的时空-文本对象到达时，如何某个CSK查询的约束可以被该新到达对象满足，该CSK查询需要立即更新。 第三，每个CSK查询可能有其独特的空间区域限制和关键字集合，而查询的空间区域可以是任何形状，包括但不限于圆形、矩形、三角形、星形等。 一个简单的方法流程如下。 每次当一个新的时空-文本对象$o$到达时，对于每一个查询集中的查询$q$, 本文需要分别计算$o$的空间信息和文本信息是否满足$q$的空间约束和文本约束。 如果$o$的空间和文本信息满足查询$q$的约束条件，则将$o$作为结果返回给查询$q$。 这个方法非常耗时，因为每次有新的对象到达时，都需要检查$o$是否匹配每个CSK查询。 在现实应用中，CSK查询集的数量可能非常大，可以是百万级，甚至是千万级。 与此同时，数据流中的时空-文本对象也是密集到达的。 因此，这种简单方法的计算成本很高，往往不能返回实时有效的结果。
    
    \item 面向大规模时空-文本对象流的相似度连接方法
    \newline \indent
    高效地处理时空-文本相似度连接问题存在以下技术难题。 首先，需要定义一个有效的相似度度量来量化两个时空-文本对象之间的相似度。 相似度度量应该考虑到两个对象之间的空间邻近性、文本相关性和时间差距。 此外，相似函数需要是轻量级的。 其次，本文的时空-文本对象的数量非常大。 本文经常需要处理数百万甚至数千万的时空-文本对象。 因此，本文的解决方案必须是可扩展的。 第三，在实际应用中，时空-文本数据流的到达频率可能很高。 本文的解决方案需要满足效率要求，并在动态数据集上返回实时的相似度连接结果。一个简单的方法如下。 给定查询集合$Q$和对象流P, 每当数据流P中有一个新的时空-文本对象$o_n$到达时，本文计算$o_n$与查询集$Q$中每一个对象$o_q$的精确相似度。如果两者相似度不小于给定的相似度阈值，本文将$(o_n,o_q)$加入查询结果集合中。由于查询集的数量可能非常大，该方法十分耗时，不能满足高效性要求。
\end{enumerate}

\section{研究内容}
基于时空文本大数据的查询以及相似性连接等问题受到了学术界和工业界的广泛关注。它们已成为位置服务中的重要应用。基于时空文本大数据的查询是根据用户输入的位置点、路线，以及关键字结合，查询同时满足关键字约束、距离约束、时间约束等约束条件的时空-文本对象。基于时空文本大数据的相似性连接问题可概括为给定一组时空-文本对象集合作为查询集，再给定一组静态或流数据形式的时空-文本对象作为数被查询数据集，返回两两匹配的二元组对象集合。在每个二元组对象里，一个来自于查询集，另一个来自于被查询数据集。本文针对时空文本大数据下复杂的查询需求，拟从以下方面展开科学研究，旨在设计对应的高性能搜索算法。
在此背景下，本研究聚焦于四类关键问题：持续最优路径规划、联合移动模式挖掘、接触搜索与轨迹相似连接。这些问题均涉及海量移动对象和复杂时空约束，典型研究意义如下：
\subsection{面向大规模时空-文本对象流的相似度连接方法}

最后，本文研究了面向大规模时空-文本对象流的相似连接问题。具体来说，给定时空-文本对象流$P$以及一组静态的时空-文本对象$Q$, 本文查询所有的时空-文本对象二元组$o_i, o_j$, 其中每一个二元组中的两个时空-文本对象$o_i\in P$, $o_j\in Q$, 并且它们的相似度不小于设定的相似度阈值$\Theta$。其中，$P$中时空-文本对象的更新速度远大于$Q$。为了解决面向大规模时空-文本对象流的相似度连接，本文具体研究内容如下。

\begin{itemize}
    \item 研究如何定义两个时空-文本对象的相似度函数。由于衡量两个对象的相似度时，同时考虑了空间接近性，文本相关性以及时间间隔这三个维度，仅仅单纯考虑某一维度的相似度或分开考虑都会导致查询结果无效。因此，需要定义一个同时考虑这三个维度的相似度函数，既能保证查询结果的准确性，又能表达不同用户的真实需求。
    \item 研究如何建立一种混合的索引结构，同时考虑空间域，文本域以及时间域。索引中不仅要包含关键字信息，也要包括时间范围信息和空间信息。该混合索引空间，时间，文本域三个维度的索引顺序有先后之分。例如，优先进行空间索引，将底层空间划分为$m\times m$个网格单元。排除不满足空间相似度阈值或范围的时空-文本对象。随后进行时间域索引，将时间划分为一组具有相等时间跨度的时间间隔,排除不满足时间间隔差的时空-文本对象。最后进行文本域索引，查找得到满足相似度阈值的时空-文本对象。
    \item 研究如何设计一种高性能连接算法。由于该问题同时考虑文本描述信息，空间位置信息以及时间间隔信息，因此该问题查询复杂度较高。若不能设计高性能查询算法，则查询效率低下，将会大大降低其应用价值。因此，需要设计一种高效的考虑多维度的连接算法，在保证查询结果精确的同时，有效减小查询空间，提高连接效率。为了进一步提升效率，可以建立有效的搜索空间修剪策略。
\end{itemize}

\subsection{面向大规模行程请求流的持续最优路线组合规划} 
交通拥堵是城市化进程中普遍存在的问题。传统路径规划往往基于单一行程或当前交通状态进行局部优化，忽略了新到达请求对未来路网负载的影响。面对持续到达的行程请求流，单次最优路径规划可能导致集中拥堵，降低整体通行效率。因此，需要设计面向持续请求流的全局协同路径规划算法，实现对时间窗口内行程请求的联合优化，从整体视角缓解交通拥堵，提高路网利用率。

\subsection{基于轨迹数据的群体联合移动模式挖掘} 
在大规模移动对象环境中，识别群体运动模式（如 flock、convoy、swarm 等）可揭示潜在的协同行为与社会动态规律。这类模式在拼车推荐、交通拥堵预测、异常行为检测以及生态监测中具有广泛应用。高效挖掘联合移动模式的核心挑战在于对象轨迹在时间上可能暂时离群或不连续，导致候选群体数量指数级增长，需要设计高效的索引结构与过滤策略以保证算法可扩展性。

\subsection{大规模移动对象上的持续密切接触发现} 
在公共卫生管理与疫情防控中，及时识别个体间潜在接触事件对于控制疾病传播具有关键意义。由于移动对象的轨迹数据通常存在采样间隔与定位误差，仅依赖离散采样点判断接触关系容易产生误判。面向大规模连续轨迹数据的接触搜索算法必须支持高并发、低延迟处理，并在动态更新环境下保证结果的准确性与一致性，为公共卫生决策提供数据支撑。

\subsection{面向时空运动范围的轨迹相似性连接方法} 
传统轨迹相似性连接方法多依赖离散采样点计算对象间距离，难以刻画未观测时间区间内的潜在交互。IS-Join 通过引入运动范围的概念，将对象在给定时间段内可能经过的空间区域作为分析单元，采用交集相似性度量量化对象间潜在重叠关系。这一方法可应用于交通监控、野生动物迁徙分析、接触追踪等场景，在稀疏采样或不确定条件下仍能稳健地识别潜在关联。


\section{论文的主要贡献}
本文面向大规模时空文本数据挖掘进行了深入的研究，提出并分析了三个新颖的关键字和时空-文本对象查询以及匹配问题(即基于给定路线的空间-文本相似位置点查询、面向时空-文本数据流的连续的空间关键字匹配、面向大规模时空-文本对象流的相似度连接)，并研究了高效能的搜索算法，现将主要贡献总结如下：
\begin{enumerate}
    \item 基于给定路线的空间-文本相似位置点查询方法
    \newline \indent
    本文针对给定路线的空间-文本相似位置点查询的隐私保护需求和高效性需求，首次提出并研究了一种新颖的，面向隐私保护的，基于给定路线的空间-文本相似的位置点(PPRSTL)搜索问题。 该研究具有十分广泛的应用，包括但不限于位置推荐和发现，以及其他很多基于位置的服务。为了解决该问题，本文定义了一个空间-文本相似度指标来评估给定路线与位置点之间的相似度关系，以及一个两阶段的搜索机制来保护用户在查询过程中的位置点偏好隐私。此外，本文提出了一个初级扩张搜索算法，该算法遵循过滤和细化范式，并借助两组上下界来高效处理PPRSTL查询。此外，本文提出了一种扩张中心点选择的选择扩张搜索算法，以及改进的中心点选择方法来更高效地计算PPRSTL查询。最后，本文在真实和合成的空间数据集上进行了广泛的实验，以验证所提出的算法的性能表现。
    
    \item 面向时空-文本数据流的连续的空间关键字匹配方法
    \newline \indent
    本文针对给定路线的空间-文本相似位置点查询的隐私保护需求和高效性需求，首次提出了一个面向大规模时空-文本位置流的CSK实时查询问题。其中每个CSK查询包括一组由“与”、“或”、“非”语义连接的关键字集合以及一个任意形状的查询区域，这些查询区域可以是任意形状。该研究具有十分广泛的应用，包括但不限于位置推荐和发现，以及其他很多基于位置的服务。为了解决该问题，本文提出了一个专为该问题设计的索引结构来有效地处理大规模的CSK查询。基于该索引结构，本文提出了一种在线的查询匹配算法。对每个新到达的时空-文本对象，该算法能够实时找到能够与该对象匹配的CSK查询子集。 最后，本文在真实数据集上进行了广泛的实验，实验结果验证了本文所提出算法的高效性。
    
    \item 面向大规模时空-文本对象流的相似度连接方法
    \newline \indent
    本文针对大规模时空-文本对象流的相似度连接需求，首次研究了一个新的问题，即实时的时空-文本相似度连接问题。该问题具有十分广泛的应用场景，比如时空-文本数据清洗，位置推荐和发现，数据分析，以及可视化等。首先，本文定义了一个有效的相似度度量用于衡量两个时空对象间的时空，空间和文本相似度。本文设计了一个三阶段的筛选框架，以及一个专门面向时空-文本对象的索引结构用于有效的组织大规模的时空-文本对象。基于该索引结构，本文提出了一系列的过滤技术和一个在线的时空-文本匹配算法。基于上述技术，三阶段筛选框架得以实时计算并返回时空-文本相似度连接的匹配结果。此外，该框架应该能够独立于相似度度量。 它适用于各种空间、时间和文本相似函数。 本文在真实数据集上进行了广泛的实验。实验结果表明本文提出的三阶段过滤框架能够实现高效力和高效性。
    
\end{enumerate}
