\zhabstract
	
随着移动互联网、定位设备以及传感技术的快速发展，大量来源广泛、更新频繁且持续增长的时空数据被不断产生。这些数据为城市计算中的交通分析、公共安全监测以及城市运行优化等应用提供了重要的数据基础。城市计算通过融合大规模时空数据分析、数据挖掘与高效算法模型，对城市运行状态进行建模与分析，从而为智能交通、公共安全与城市管理等应用提供技术支撑。然而，在真实应用环境中，轨迹等时空数据往往具有规模巨大、持续到达以及动态演化等特点，使得传统算法在计算效率与可扩展性方面面临显著挑战。因此，如何在大规模动态轨迹数据环境下设计高效的计算方法，已成为城市计算领域的重要研究问题。

围绕上述问题，本文以大规模动态轨迹数据上的高效计算为研究主线，针对城市计算中具有代表性的四类任务，即路径规划、轨迹模式挖掘、时空接触关系搜索以及轨迹相似关系分析开展系统研究。通过深入分析各类问题在大规模数据环境下所面临的搜索空间巨大、候选对象规模庞大以及实时计算需求等挑战，本文提出了一系列高效的算法模型与优化策略。主要研究内容与创新成果如下。

1. 提出并研究了城市计算中面向大规模行程请求流的全局持续最优路线组合规划问题。在路径规划服务广泛应用的背景下，大量用户会在短时间内持续提交行程请求，形成高密度的请求流。该问题需要在动态路网环境下为一组持续到达的行程请求规划一组路线组合，使得整体通行时间最小。然而，随着请求数量的增加，可行路径组合的规模呈指数级增长，使得精确搜索难以满足实时计算需求。为此，本文设计了一种自感知批处理算法，通过初始路径搜索生成一组能够避免部分交通拥堵的初始路线，并进一步对最近到达的请求集合进行批量优化处理，从而有效降低潜在拥堵。基于真实数据集的实验结果表明，所提出方法相比基线方法能够降低超过 40\% 的总通行时间。

2. 提出并研究了城市计算中群体联合移动模式挖掘问题。群体移动模式能够揭示移动对象之间的协同行为，对交通模式分析与群体行为理解具有重要意义。现有方法在模式表达能力与计算效率之间往往难以取得平衡。为此，本文提出一种放宽的伴随群体模式定义，允许对象在部分时间段暂时离开群体，从而更加符合现实移动行为特征。针对该模式挖掘任务，本文首先设计了一种精确搜索算法，通过对候选对象对与候选群体进行精确验证以保证结果的完备性。为进一步提升算法效率，本文提出了一种社区感知的近似搜索算法，通过近似计算与结构化聚类方法有效压缩搜索空间。实验结果表明，所提出方法能够在大规模轨迹数据中高效搜索伴随群体。在运行时间方面，近似算法相较于精确算法实现了数量级上的性能提升。

3. 提出并研究了城市计算中面向大规模移动对象的持续暴露接触搜索问题。在公共安全与疾病传播控制等应用中，需要从持续到达的轨迹位置流中实时搜索潜在的暴露接触事件。已有方法通常假设数据完整可得，难以直接应用于持续更新的轨迹数据环境。针对这一问题，本文提出了一种面向轨迹流的分组处理框架，包括精确分组处理算法与近似分组处理算法，并设计了分组过滤与预检查等优化策略，以减少候选对象规模并提升检测效率。实验结果表明，所提出方法在不同数据规模与参数设置下均能够显著降低计算时间。

4. 提出并研究了城市计算中运动范围感知的轨迹交集相似度连接问题。由于采样频率不一致、定位误差以及采样间隔内运动过程不可观测等因素，轨迹数据往往具有不确定性与稀疏性特征。传统方法通常基于离散采样点进行相似度计算，难以准确反映对象在采样间隔内的连续运动状态。为此，本文以对象在时间区间内的潜在运动范围为基本分析单元，引入交集相似度度量以刻画对象之间的潜在交互关系。针对连续时间区间下计算复杂以及候选对象对规模庞大的问题，本文提出一种由时间区间运动范围引导的高效求解框架，并设计了混合球树索引结构以及多级剪枝策略，实现对候选对象对的有效过滤。

综上，本文围绕大规模动态轨迹数据上的高效计算问题，针对城市计算中的多类典型任务提出了系统性的算法方法与优化技术。相关研究成果可广泛应用于城市交通拥堵预防、拼车推荐、群体行为分析、疾病传播控制以及异常轨迹检测等实际场景，为大规模时空数据驱动的城市智能化分析提供了有效的技术支持。

\enabstract

With the rapid development of mobile Internet, positioning devices, and sensing technologies, a large amount of spatio-temporal data is continuously generated. These data come from many sources, are frequently updated, and keep growing. They provide an important data foundation for many urban computing applications, such as traffic analysis, public safety monitoring, and urban operation optimization. Urban computing integrates large-scale spatio-temporal data analysis, data mining, and efficient algorithm models to model and analyze urban dynamics. It provides technical support for applications such as intelligent transportation, public safety, and urban management. However, in real-world environments, trajectory data often have several characteristics, including large scale, continuous arrival, and dynamic evolution. These characteristics bring significant challenges to traditional algorithms in terms of computational efficiency and scalability. Therefore, designing efficient computation methods for large-scale dynamic trajectory data has become an important research problem in urban computing.

To address this problem, this dissertation focuses on efficient computation on large-scale dynamic trajectory data. It conducts systematic studies on four representative tasks in urban computing, namely route planning, trajectory pattern mining, spatio-temporal contact discovery, and trajectory similarity analysis. By analyzing the common challenges of these tasks under large-scale data environments, including huge search spaces, large numbers of candidate objects, and real-time computation requirements, this dissertation proposes a series of efficient algorithm models and optimization strategies. The main research contributions are summarized as follows.

1. This dissertation studies the gloabl continuous optimal route combination planning problem for large-scale trip request streams in urban computing. With the wide use of route planning services, many users submit trip requests within a short time. This leads to a high-density request stream. The goal of this problem is to plan a set of routes for continuously arriving trip requests on a dynamic road network, such that the total travel time is minimized. However, as the number of requests increases, the number of feasible route combinations grows exponentially. This makes exact search difficult for real-time computation. To address this issue, this dissertation proposes a self-aware batch processing algorithm. The algorithm first performs an initial path search to generate a set of initial route combinations that can avoid some traffic congestion. Then it performs batch optimization on recently arrived requests to further improve the route combinations and reduce potential congestion. Experimental results on real datasets show that the proposed method reduces the total travel time by more than 40\% compared with baseline methods.

2. This dissertation studies the group comovement pattern mining problem in urban computing. Group movement patterns reveal collaborative behaviors among moving objects. They are important for traffic pattern analysis and group behavior understanding. Existing methods often face a trade-off between pattern expressiveness and computational efficiency. To address this issue, this dissertation proposes a relaxed convoy pattern definition. It allows objects to temporarily leave the group during some time intervals without breaking the overall pattern. This definition better reflects real-world movement behaviors. For this mining task, an exact search algorithm is first designed. It verifies candidate object pairs and candidate groups to guarantee result completeness. To further improve efficiency, a community-aware approximate search algorithm is proposed. It uses approximate computation and structured clustering methods to effectively reduce the search space. Experimental results show that the proposed methods can efficiently discover convoy patterns from large-scale trajectory datasets. In terms of runtime, the approximate algorithm achieves an order-of-magnitude improvement over the exact algorithm.

3. This dissertation studies the continuous exposure contact discovery problem for large-scale moving objects in urban computing. In applications such as public safety and disease spread control, it is necessary to detect potential exposure contacts from continuously arriving trajectory location streams in real time. Existing methods usually assume that trajectory data are fully available. Therefore, they cannot be directly applied to continuously updated trajectory environments. To address this problem, this dissertation proposes a group-based processing framework for trajectory streams. The framework includes an exact group processing algorithm and an approximate group processing algorithm. It also introduces optimization techniques such as group filtering and pre-checking. These techniques reduce the number of candidate objects and improve detection efficiency. Experimental results show that the proposed methods significantly reduce computation time under different data sizes and parameter settings.

4. This dissertation studies the movement-range-aware trajectory intersection similarity join problem in urban computing. Due to inconsistent sampling frequencies, positioning errors, and the unobservable movement between sampling points, trajectory data often have uncertainty and sparsity. Traditional methods usually compute similarity based on discrete sampling points. Therefore, they cannot accurately reflect the continuous movement of objects within sampling intervals. To address this issue, this dissertation uses the potential movement range of objects within a time interval as the basic analysis unit. It introduces an intersection-based similarity measure to quantify the overlap between movement ranges. To handle the high computation cost and the large number of candidate object pairs, an efficient computation framework guided by time-interval movement ranges is proposed. The framework designs a hybrid ball-tree index structure and adopts multi-level pruning strategies to effectively filter candidate object pairs.

In summary, this dissertation studies the problem of efficient computation on large-scale dynamic trajectory data. It proposes systematic algorithmic methods and optimization techniques for several typical tasks in urban computing. The proposed methods can be widely applied in many real-world scenarios, including urban traffic congestion prevention, ride-sharing recommendation, group behavior analysis, disease spread control, and abnormal trajectory detection. These studies provide effective technical support for intelligent urban analysis driven by large-scale spatio-temporal data.
